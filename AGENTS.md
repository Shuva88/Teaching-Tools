# Teaching Tools Project Instructions

Before adding a new algorithm or changing an existing demonstration:

1. Read `README.md` and `CLASSROOM_DISPLAY_GUIDELINES.md`.
2. Treat the classroom display guidelines as required acceptance criteria, not
   optional design suggestions.
3. Preserve established algorithm logic, data, tie handling, and calculations
   unless the user explicitly requests a substantive change.
4. Keep algorithm logic separate from Streamlit display logic.
5. Run focused algorithm tests and exercise every presentation state locally.
6. Restart Streamlit after changing an imported display component, refresh the
   browser, and visually check the deployed app before considering display work
   complete.
7. Register an algorithm in `app.py` only when it is ready for student release.
